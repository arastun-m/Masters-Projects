Computes an orthographic projection of a 3D volume.

Projects a volumetric dataset into a 2D image using various projection methods:

  • MIP (Maximum Intensity Projection)
  • MinIP (Minimum Intensity Projection)
  • meanAIP (Average Intensity Projection)
  • medianAIP (Median Intensity Projection)
Parameters
volumeThe input 3D volume.
typeThe projection type ("MIP", "MinIP", "meanAIP", "medianAIP").
minZThe starting slice (1-indexed).
maxZThe ending slice (1-indexed, 0 for full depth).
Returns
A unique pointer to the projected 2D image, or nullptr if input is invalid.
