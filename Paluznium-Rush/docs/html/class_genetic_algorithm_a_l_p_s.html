Detailed Description

Genetic Algorithm class for the ALPS (Age-Layered Population Structure) approach.

This class implements the ALPS genetic algorithm for optimization problems, with a focus on reducing premature convergence. It includes methods for population initialization, injections, selection, crossover, mutation, and aging of individuals.
