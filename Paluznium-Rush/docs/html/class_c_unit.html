Detailed Description

Represents a single processing unit in the mineral processing circuit.

Provides methods for setting connections, resetting state, and calculating output streams based on first-order kinetic relationships.

void CUnit::calculateOutputs ( double paluszniumFeed,
double gormaniumFeed,
double wasteFeed )
inline

Calculate recoveries and flowrates based on input feeds.

Implements the first-order kinetic relationship for material recovery:

  1. Calculate residence time (τ) = (φ * V) / Σ(Fi/ρ)
  2. Calculate recovery rates (Ri) = (ki * τ) / (1 + ki * τ) for each material
  3. Calculate output streams
