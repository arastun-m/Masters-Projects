std::vector< Algorithm_Parameters > load_all_configs ( const std::string & filename)

Load multiple algorithm configurations from a JSON file.

This function reads a JSON file containing one or more configuration objects and returns a vector of Algorithm_Parameters. If the file contains a single object, it is wrapped in an array for consistency.

Parameters
filenamePath to the JSON configuration file.
Returns
std::vector<Algorithm_Parameters> Vector of loaded configuration parameters.
Exceptions
std::runtime_errorIf the file cannot be opened.
